# Film tonight: design direction

- Color: paper `#ffffff`, sky `#edf5fc`, ink `#142d4e`, cobalt `#174fc4`, rule `#c7d7e7`, caution `#805017`.
- Type: Georgia for the compact cinema-listing title; system sans for controls and listings. Tabular numerals keep showtimes aligned. No font downloads.
- Layout: left-aligned title, a compact filter strip, chronological listings, then an optional map. On narrow screens each table row becomes a labelled listing, not a horizontally scrolling spreadsheet.

```text
Film tonight                 Prague / Europe/Prague
Date · from · English access · search
More filters                results / refresh
Time | Film | Cinema | English access | Tickets
Coverage disclosure
Map (loaded only when requested)
```

Review: a large editorial hero and individual film cards would repeat generic discovery-site patterns and slow down the decision. Revised to a modest title and one practical timetable. Blue time labels and the calm sky background borrow from public transport wayfinding: find a departure, check the destination, go. Borders separate information, not decorative panels. Evidence and coverage remain close to the listings; uncertain language never masquerades as confirmed English access.

Principles: table before tiles; a location is an explicit, ephemeral choice; no invented availability; usable without a map; plain explanations for missing coverage and failures. No animation is needed.
